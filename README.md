# Modern Glassmorphism Search Bar

A modern, minimal, and elegant **search bar UI component** built with pure **HTML, CSS, and JavaScript**.  
Designed with a glassmorphism aesthetic, smooth micro-interactions, and a focus on clean UX.  
No external libraries or frameworks required.

---

## ✨ Features

- Glassmorphism design with backdrop blur
- Smooth hover and focus animations
- Fully responsive layout
- Clean, reusable component structure
- Lightweight and framework-free
- Built-in **“Get Code”** modal with copy-to-clipboard functionality
- Keyboard accessible (ESC to close modal)
